# 寝かしつけ朗読：ナレーション＋スライド用プロンプト作成

3〜6さいの子どもが **自然にねむくなる** 朗読台本と、それに合わせた **スライド画像の生成プロンプト** を作る。
動画自体はユーザーが Canva で手作業で作るので、Canva でそのまま使える形にまとめる。

依頼内容: $ARGUMENTS

## 手順

1. **依頼を確認する**
   依頼から テーマ・主人公・長さ・シリーズ（既存キャラのポポを使うか）を読み取る。
   書かれていない項目は下の既定値で進め、最後の報告で「こうしました」と一言そえる。質問で止めない。
   - 長さ：朗読 約 5〜6 分（8〜10 場面、1 場面 30〜55 秒）
   - 主人公：指定がなければ新しい動物キャラを 1 体考える（既存シリーズ希望ならポポ → `references/style-guide.md`）
2. **台本を書く** — 下の「ナレーションのルール」を必ず守る。
3. **プロンプトを書く** — `references/style-guide.md` の共通スタイル・キャラ設定・書き方に従う。
4. **ファイルに書き出す** — `references/template.md` の構成で `canva/<slug>.md` を作る
   （slug は英小文字とアンダースコア、例：`usagi_star_train`）。完成例：`canva/popo_moon_boat.md`。
5. **チェックする**
   ```bash
   python3 .claude/skills/bedtime-script/scripts/check_script.py canva/<slug>.md
   ```
   警告が出たら、本当にオノマトペ等か判断して直し、エラーがなくなるまでくり返す。
   さらに下の「最終チェックリスト」を自分で確認する。
6. **README の一覧に追加**し、コミットしてプッシュする（リポジトリのブランチ運用に従う）。
7. **報告** — 場面の一覧表（場面・内容・目安秒数）と、既定値で決めたことを短く伝える。

ユーザーが自動生成パイプライン（`python -m bedtime.build`）でも動画を作りたいと言ったときだけ、
同じ台本で `stories/<slug>.yaml` も作る（書式は `stories/popo_moon_boat.yaml` を参照。`art:` は既存の絵の名前から選ぶ）。

## ナレーションのルール（必須）

### 絶対に守ること
- **擬音語・擬態語（オノマトペ）を使わない。**
  「すー」「ふー」「すやすや」「ぽかぽか」「ゆらゆら」「ふわふわ」「きらきら」「しーん」「にっこり」「ぐっすり」「ふわぁ〜（あくび）」などは使わず、ふつうの言葉で言いかえる。
  - 例：ぽかぽか → あたたかい／ふわふわの → やわらかい／きらきら ひかる → ひかりながら ゆれる／
    すーっと すって → ゆっくり いきを すって／しーんと → とても しずかに／にっこり → うれしそうに／
    ゆら、ゆら → みぎへ、ひだりへ
  - 「ゆっくり」「だんだん」「そっと」は、ふつうの副詞として使ってよい。
- **こわい・ドキドキする要素を入れない。** 悪者、大きな音、けんか、迷子、暗闇へのおそれ、急な展開は不可。
- **ひらがな中心・分かち書き**（文節ごとに半角スペース）。カタカナは名前など最小限。漢字は使わない。
- 1 文は字幕で 2 行以内（目安 30 文字以内）。

### ねむりをさそう構成
- 全体の流れ：**夕方・おうち → 夜のおさんぽ（しずかな場所をめぐる）→ 深い夜 → おふとん → 聞いている子への「おやすみなさい」**。
- 後半ほど、場面を暗く・しずかに、文を短く、間を長くする。
- 次の要素を必ず入れる：
  1. **くり返し**（例：「ひつじさんが、ひとり。…ふたり。…」「○○さんも、おやすみ。」）。数える場面は 5 まで、間を少しずつ延ばす。
  2. **呼吸の誘導**（例：「はなから、ゆっくり、いきを すって。」「くちから、ゆっくり、いきを はいて。」を 2 回）。
  3. **からだへの意識**（例：「てのさきも、あしのさきも、あたたかい。」）。
  4. **ねぎらい**（例：「きょうも いちにち、よく がんばったね。」）。
  5. **さいごの語りかけ**（例：「そして、これを きいている、あなたも。…おやすみなさい。」）。
- 各文のあとに `（間 ○秒）` を書く。目安：ふつう 1.8 秒、場面の最後 2.5〜3 秒、数える・呼吸 2.2〜3 秒、最後の「おやすみなさい」4 秒。
- 場面ごとの目安の長さ ≒（文字数 × 0.2 秒）＋ 間の合計 ＋ 切りかえ 2 秒。

### 読みかたメモ・Canva メモ
- 場面ごとに必要なら「読みかたメモ」（声の大きさ・速さ・ささやく等）と「Canva メモ」（パン・ズーム・フェード等の演出）を 1〜2 行つける。
- 演出は **ゆっくりしたものだけ**（ディゾルブ、ゆっくりパン・ズーム）。はねる・回る・点滅は使わない。

## 最終チェックリスト
- [ ] `check_script.py` がエラーなしで通る
- [ ] ナレーションにオノマトペが 1 つもない（自分の目でも全文を読み直す）
- [ ] こわい・ドキドキする要素がない
- [ ] くり返し・呼吸・からだ・ねぎらい・さいごの語りかけ が入っている
- [ ] 後半ほど暗く・しずかになるよう、プロンプトの色指定も暗くなっている
- [ ] すべての場面に 英語・日本語 の画像プロンプトがあり、`no text` 指定がある
- [ ] キャラクターの見た目の説明が全場面で同じ言葉になっている
- [ ] 目安の長さの合計が依頼の長さに近い
